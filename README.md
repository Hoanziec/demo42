# STEM Lớp 4 – Vật dẫn nhiệt tốt, vật dẫn nhiệt kém

## GitHub Pages
1. Upload toàn bộ các file trong thư mục này lên repository.
2. Giữ `index.html`, `home.jpg`, `explore.jpg`, `video1.mp4`, `video2.mp4` cùng cấp.
3. Bật GitHub Pages từ branch `main` và thư mục `/ (root)`.

Thanh điều hướng gồm Trang chủ → Thử thách → Khám phá → Ý tưởng và khóa các phần phía sau cho đến khi phần trước được hoàn thành.
